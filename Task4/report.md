# Проблемы и решения

- **Инфраструктура**
  - **Единственный собственный сервер:** перенести инфраструктуру в облако; рассмотреть применение гибридной архитектуры
  - **Нет репликации:** реализовать репликацию с несколькими зонами достуности
  - **Сервер в офисе компании:** перенести инфраструктуру в облако или гибрид
- **Программное обеспечение**
  - **Санкционные риски**: при выборе ПО отдавать предпочтение отечественным продуктам или ПО с открытым исходным кодом
  - **Устаревшее ПО:** провести ревизию используемого программного обеспечения
  - **Уязвимости ПО:** внедрить мониторинг
- **Интеграция**
  - **Контракты API:** разработать и документировать контракты API для интеграций при помощи стандартных инструментов (OpenAPI, AsyncAPI)
  - **Аутентификация и авторизация:** внедрить существующие продукты IDP (Keycloak)
  - **Безопасность данных:** использовать шифрование данных при хранении и передаче; анонимизировать данные при возможности; тэгировать и классифицировать данные
- **Персонал**
  - **Обучение:** документировать изменения и процессы, вести обучение сотрудников
  - **Сопротивление изменениям:** вести обучение сотрудников, разъяснять целесообразность проводимых изменений, представить роадмап развития компании
  - **Выявление знаний:** проводить работу с сотрудиками, документировать выявленные сведения
- **Процессы**
  - **Адаптация процессов:** существующие процессы должны быть изменены и адаптированы для работы в новых условиях
  - **Усложнение процессов:** детальное документирование новых процессов, мониторинг качества документации
