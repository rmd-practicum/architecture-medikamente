# Данные для защиты

- Личные данные клиентов: шифрование
- Медицинская информация клиентов: обезличивание
- Данные бухгалтерии и склада: шифрование
- Финансовые данные: шифрование
- Внутренняя коммуникация (почта): шифрование
- Данные для аналитики: обфускация

# Механизм тегирования данных

- Классификация данных
- Тегирование данных на основе результатов классификации
- Мониторинг тегирования
